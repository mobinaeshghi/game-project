# Peer review reports

پس از دریافت مخزن دو هم‌کلاسی و اجرای تست‌های خودتان، گزارش واقعی هر بررسی را در فایل جداگانه ثبت کنید.

برای هر گزارش بنویسید:
- آدرس مخزن بررسی‌شده
- نام تست اجراشده
- رفتار مورد انتظار
- نتیجه واقعی
- تحلیل اینکه اشکال از تست است یا پیاده‌سازی

گزارش ساختگی یا گزارش بدون اجرای واقعی تست ننویسید.
